Lease ≠ Session

Live client does not mean live authority. Mutation ownership must expire/reacquire independently of a connected session.

DONE ≠ Evidence

Worker self-report cannot prove external completion. The requested result must be observed.

Rollback ≠ Resurrection

Rollback must not restore deprecated authority. Historical state cannot silently become current truth again.
