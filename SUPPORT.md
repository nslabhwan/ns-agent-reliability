# Support

## Setup, usage, and alpha feedback

Use the [OpenSynapse Alpha feedback form](https://github.com/nslabhwan/ns-agent-reliability/issues/new?template=opensynapse-feedback.yml) for installation problems, first-task friction, and usage questions.

Please include only the minimum public-safe context: operating system/device class, Python version when relevant, the last step that worked, the first step that failed, and the real task you were trying to complete.

Do not post credentials, tokens, cookies, private URLs, private logs, customer data, or production secrets.

## Security issues

For sensitive security reports, use GitHub Private Vulnerability Reporting from the repository Security tab as described in [SECURITY.md](SECURITY.md). Do not open a public issue containing secrets or exploit details that would put users at risk.

## Current alpha boundary

Linux and Android/Termux local bounded-node paths are public alpha surfaces. A real authorized OpenAI account -> ChatGPT -> OpenSynapse end-to-end path is still an explicit verification boundary until that exact path is publicly observed.
